# ADB סטודיו

ממשק גרפי פשוט, נקי ובעברית לניהול טלפון אנדרואיד מהמחשב — בלי פקודות ובלי כאב ראש.

## מה אפשר לעשות

| | |
|---|---|
| **סקירה** | דגם, גרסת אנדרואיד, סוללה, אחסון, זיכרון ומסך במבט אחד |
| **אפליקציות** | חיפוש, פתיחה, עצירה, ניקוי נתונים, גיבוי APK למחשב והסרה |
| **התקנת APK** | בלחיצה או בגרירת הקובץ לחלון |
| **קבצים** | דפדוף בטלפון, העלאה (גם בגרירה), הורדה, יצירת תיקייה ומחיקה |
| **צילום מסך** | תצוגה מקדימה ושמירה למחשב (רווח = צילום, Ctrl+S = שמירה) |
| **טרמינל** | הרצת פקודות `adb shell` עם היסטוריה ופקודות מהירות |
| **חיבור אלחוטי** | מעבר מכבל ל-Wi‑Fi בלחיצה, או צימוד בקוד (אנדרואיד 11+) |
| **הפעלה מחדש** | רגילה, Recovery או Bootloader |

מצב כהה ובהיר, ותמיכה בכמה מכשירים במקביל.

## התקנה (Windows) — בלי Python ובלי כלום

1. מורידים את **`ADB-Studio-Setup.exe`** (מעמוד ה-Releases או מה-Artifacts של GitHub Actions).
2. לוחצים פעמיים → "התקן". לא צריך הרשאות מנהל, ו-ADB כבר כלול בפנים.
3. נוצר קיצור דרך בשולחן העבודה ובתפריט התחל. זהו.

> הקובץ לא חתום דיגיטלית, ולכן Windows עשוי להציג "Windows הגן על המחשב שלך".
> לוחצים **"מידע נוסף" ← "הפעל בכל זאת"**.

מעדיפים בלי התקנה? יש גם `ADB-Studio-Portable.zip` — מחלצים ומפעילים את `ADBStudio.exe`.

הסרה: הגדרות ← אפליקציות ← ADB סטודיו ← הסר.

## הפעלה מקוד המקור (Mac / Linux / מפתחים)

1. צריך **Python 3.9 ומעלה**. אין צורך בשום ספרייה נוספת.
2. `./start.sh` ב-Mac/Linux, `start.bat` ב-Windows, או `python adb_studio.py`.
3. אם ADB לא מותקן — לוחצים **"התקנה אוטומטית"** והתוכנה מורידה אותו מגוגל.

## חיבור הטלפון

1. **הגדרות ← אודות הטלפון** ← הקישו 7 פעמים על "מספר Build"
2. **הגדרות ← מערכת ← אפשרויות מפתחים** ← הפעילו "ניפוי באגים ב-USB"
3. חברו כבל ואשרו את החלון שקופץ בטלפון

## פרטים טכניים

- `adb_studio.py` — שרת מקומי קטן (ספריית התקן של Python בלבד) שמפעיל את `adb`.
- `web/` — הממשק (HTML/CSS/JS ללא תלויות).
- החלון נפתח ב-Chrome / Edge / Brave במצב אפליקציה; אם אין כזה — בדפדפן ברירת המחדל.
- השרת מאזין רק ל-`127.0.0.1` ודורש מפתח גישה אקראי שנוצר בכל הפעלה, כך שאתרים אחרים לא יכולים לשלוח פקודות לטלפון.
- ADB מחפש לפי הסדר: משתנה הסביבה `ADB_PATH`, תיקיית `platform-tools` ליד התוכנה, `~/.adb-studio/platform-tools` (התקנה אוטומטית), `PATH`, ו-Android SDK.
- קובץ ההתקנה נבנה אוטומטית ב-GitHub Actions (`.github/workflows/build.yml`) עם PyInstaller ו-Inno Setup. דחיפת תגית `v1.2.3` מפרסמת Release.
- `python adb_studio.py --no-window` — מריץ בלי לפתוח חלון ומדפיס את הכתובת.
