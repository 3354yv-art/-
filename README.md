# hebfix – יישור עברית בשורת הפקודה

כשמתכתבים עם AI בטרמינל (Claude Code, Gemini CLI, Codex, aider, ollama ועוד), הרבה טרמינלים
לא יודעים להציג טקסט מימין לשמאל, והעברית יוצאת **הפוכה** (`םולש` במקום `שלום`).

**hebfix** הוא תוסף שמתחבר לשורת הפקודה בדרך קבע, יושב בין הטרמינל לבין התוכנות שרצות בו,
ומיישר כל טקסט בעברית לפני שהוא מוצג, בלי לשבור צבעים, מסגרות, תנועות סמן או מסכים מלאים.

## התקנה

```bash
git clone <כתובת-הריפו> hebfix
cd hebfix
./install.sh
```

זהו. מעכשיו כל חלון מסוף חדש (bash או zsh) עובר דרך hebfix אוטומטית.

רוצים שהתיקון יחול **רק על כלי AI** ולא על כל המסוף?

```bash
./install.sh --ai-only
```

זה עוטף את הפקודות: `claude`, `gemini`, `codex`, `aider`, `ollama`, `sgpt`, `llm`, `chatgpt`,
`copilot`, `cursor-agent`, `qwen`, `opencode`.

דרישות: Linux, macOS או WSL (ב-Windows). **לא צריך להתקין שום דבר** (לא Python ולא ספריות אחרות):
בתיקייה `dist/` יש קבצי הרצה מוכנים, וההתקנה בוחרת לבד את המתאים למחשב שלכם
(Linux Intel/AMD, Linux ARM כולל Raspberry Pi, ו-Mac Intel או Apple Silicon).

## שימוש

| פקודה | מה היא עושה |
|---|---|
| `hebfix toggle` | כיבוי/הדלקה זמניים במסוף הנוכחי |
| `hebfix off` / `hebfix on` | כיבוי / הדלקה |
| `hebfix status` | האם המסוף הנוכחי עובר דרך hebfix |
| `hebfix claude` | הרצה חד-פעמית של פקודה דרך hebfix (בלי התקנה) |
| `פקודה \| hebfix --pipe` | יישור פלט של פקודה שאינה אינטראקטיבית |
| `HEBFIX_DISABLE=1` | משתנה סביבה שמונע את ההפעלה האוטומטית |
| `--base ltr\|rtl\|auto` | כיוון הפסקה (ברירת מחדל: `auto` לפי האות החזקה הראשונה בשורה) |

## הסרה

```bash
~/.local/share/hebfix/uninstall.sh
```

## איך זה עובד

- hebfix מריץ את ה-shell (או את הפקודה) בתוך מסוף וירטואלי (PTY), כך שכל הפלט עובר דרכו.
- כל קטע טקסט שמכיל עברית מסודר מחדש לפי גרסה מפושטת של אלגוריתם ה-Bidi של Unicode:
  מילים בעברית מתהפכות, מספרים ומילים באנגלית נשארים משמאל לימין, סוגריים משתקפים,
  וניקוד נשאר צמוד לאות.
- שורה שמתחילה בעברית מוצגת כפסקה מימין לשמאל; תבליטים, מספור רשימות, רווחים ומסגרות
  (`│ ● - 1.`) נשארים במקומם כדי ששורות ותיבות לא יישברו.
- מספר התווים בשורה לא משתנה, ולכן תוכנות מסך מלא (כמו ממשקי AI) ממשיכות לעבוד כרגיל.
- שורות ארוכות שהטרמינל גולש מסודרות לפי כל שורה על המסך בנפרד.
- אם משהו נכשל בהפעלה, המסוף נפתח כרגיל, כך שהתקנה שבורה אף פעם לא נועלת אתכם בחוץ.

## הגבלות ידועות

- **אם הטרמינל שלכם כבר תומך בעברית** (למשל Konsole, או gnome-terminal חדש עם bidi מופעל),
  hebfix יהפוך את הטקסט פעמיים. במקרה כזה אין צורך בו; כבו אותו עם `hebfix off` או הסירו אותו.
- טקסט **שאתם מקלידים** בשורת הפקודה מוצג תו-אחר-תו ולכן עדיין עשוי להיראות הפוך בזמן
  ההקלדה. הפלט שחוזר מה-AI מוצג כראוי.
- האלגוריתם הוא קירוב של תקן Unicode Bidi ולא מימוש מלא, אבל הוא מכסה את רוב המקרים
  (עברית, עברית עם אנגלית, מספרים, פיסוק וניקוד).

## פיתוח

הקוד כתוב ב-Go. צריך Go רק כדי לבנות מחדש, לא כדי להשתמש בתוסף.

```bash
go test ./...   # בדיקות
./build.sh      # בניית קבצי ההרצה לתיקייה dist/
```
