AdBlock - חוסם פרסומות ומעקבים לכל האפליקציות במחשב
====================================================

איך זה עובד
-----------
כל אפליקציה (דפדפן, משחקים, Spotify, תוכנות...) שואלת DNS לפני שהיא מתחברת
לשרת פרסומות. התוכנה היא שרת DNS מקומי שעונה 0.0.0.0 לכ-75,000 דומיינים של
פרסומות/מעקב, ומעביר את השאר ל-1.1.1.1 / 9.9.9.9. לא צריך להתקין כלום בכל אפליקציה.

דרישות: Python 3.8+ בלבד (ללא חבילות נוספות).

Windows
-------
לחיצה כפולה על Start.bat (יבקש הרשאות מנהל). הוא מוריד רשימות, מפנה את ה-DNS
של המחשב אליו ומריץ. Ctrl+C מחזיר את ה-DNS המקורי.

macOS / Linux
-------------
    sudo python3 adblock.py update
    sudo python3 adblock.py set-dns      # macOS; ב-Linux הגדר nameserver 127.0.0.1
    sudo python3 adblock.py run
    sudo python3 adblock.py restore-dns

כל המכשירים ברשת הביתית (טלפונים, טלוויזיה): הרץ על מחשב שתמיד דלוק עם
    python adblock.py run --listen 0.0.0.0
והגדר ב-DHCP של הראוטר (או ב-DNS של כל מכשיר) את כתובת המחשב הזה.

התאמה אישית
-----------
  allowlist.txt     דומיינים שלא ייחסמו (אם משהו "נשבר") - שורה לדומיין
  custom-block.txt  דומיינים נוספים לחסימה
  python adblock.py check example.com   בדיקה אם דומיין חסום
  python adblock.py run -v              הצגת כל דומיין שנחסם
  python adblock.py update              עדכון הרשימות (מומלץ פעם בשבוע)

מגבלות (חשוב לדעת)
------------------
* חסימת DNS לא יכולה לחסום פרסומות שמגיעות מאותו דומיין של התוכן
  (למשל פרסומות ביוטיוב, או פרסומות בתוך אפליקציות שמשרתות אותן מהשרת שלהן).
* אפליקציות/דפדפנים עם DNS-over-HTTPS מובנה עוקפים את ה-DNS של המערכת.
  בדפדפן: בטל "Secure DNS"/"DNS over HTTPS" בהגדרות.
* Android/iOS: אי אפשר להפעיל שרת כזה בתוך הטלפון בלי אפליקציה. הפתרון הקל:
  הרצה על מחשב/Raspberry Pi ברשת והגדרת DNS פרטי, או אפליקציות מוכנות
  כמו AdAway / Blokada / AdGuard.
