# Forum Helper – סקריפט Tampermonkey לפורומים

## התקנה
1. התקן את Tampermonkey:
   - Chrome: https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo
   - Firefox: https://addons.mozilla.org/firefox/addon/tampermonkey/
   - Edge: https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd
   - אתר רשמי: https://www.tampermonkey.net/
2. לחץ על קישור ההתקנה של הסקריפט:
   https://raw.githubusercontent.com/3354yv-art/-/main/tools/forum-userscript/forum-helper.user.js
   Tampermonkey ייפתח ויציע ללחוץ **Install**.

## תכונות
- 🌙 מצב כהה (מתפריט Tampermonkey)
- ▲ כפתור חזרה למעלה
- כיווץ ציטוטים ארוכים
- 🔍 הדגשת מילות מפתח (מתפריט Tampermonkey)

הסקריפט פועל על כתובות שמכילות forum / thread / topic. להוספת פורום ספציפי – ערוך את שורות `@match`.
