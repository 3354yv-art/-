צריבת קושחה ל-QLYX Q8 (קיוליקס) / QLYX Q8 Firmware Flasher
==========================================================

מה התוכנה עושה:
  1. בודקת את קובץ הקושחה (.pac) לפני הצריבה – שהוא שלם, לא פגום (CRC),
     ושהוא מיועד ל-Q8. קובץ פגום או של דגם אחר הוא הסיבה מספר 1 לטלפון "מת".
  2. מזהה כשהטלפון מחובר במצב צריבה – עוזר למצוא את מקש הצריבה.
  3. מגבה את הקושחה שיש עכשיו בטלפון (עם spd_dump), כדי שאפשר יהיה לחזור אחורה.
  4. פותחת את כלי הצריבה הרשמי (ResearchDownload) ומדריכה צעד אחר צעד.

איך מפעילים:
  1. חלץ את קובץ ה-ZIP לתיקייה (לחיצה ימנית > חלץ הכל).
  2. לחיצה כפולה על Start.bat.
  אם מופיע "Windows protected your PC": "מידע נוסף" ואז "הפעל בכל זאת".

מה צריך להשיג לבד (התוכנה לא כוללת אותם):
  * קובץ הקושחה (.pac) של QLYX Q8 – מהיבואן, ממעבדה מורשית, או מפורום
    "מתמחים טופ". חשוב: רק קושחה לדגם Q8 בדיוק!
  * ResearchDownload (SPD Research Tool) + דרייבר SPD – לצריבה.
    https://spdflashtool.com
  * (לגיבוי) spd_dump.exe + הדרייבר WinUSB:
    https://github.com/ilyakurdyukov/spreadtrum_flash/releases
    את הדרייבר מתקינים עם Zadig (https://zadig.akeo.ie): מחברים את הטלפון במצב
    צריבה, ב-Zadig בוחרים Options > List All Devices, בוחרים את ההתקן
    1782:4D00 ומתקינים WinUSB. אחרי הגיבוי, לפני הצריבה, מחזירים את הדרייבר
    של SPD: מנהל ההתקנים > ההתקן > הסר התקן (עם סימון "מחק את מנהל ההתקן"),
    ואז מתקינים שוב את דרייבר ה-SPD.

אזהרות – חשוב לקרוא:
  * צריבה עצמית מבטלת את האחריות.
  * המכשיר מאושר כשר עם קושחה מסוימת. צריבה של גרסה אחרת (גם רשמית) עלולה
    לפגוע באישור הכשרות – כדאי לברר מול היבואן/ועדת הרבנים לפני כן.
  * אל תנתק את הכבל באמצע הצריבה. סוללה טעונה לפחות ל-50%.
  * הטלפון של הדגם הזה משתמש בשבב Unisoc (סביר שממשפחת T107/T117 של טלפוני
    מקשים 4G). היצרן לא פרסם את הדגם המדויק, ולכן גם את מקש הצריבה צריך
    למצוא בניסוי (לשונית 2 בתוכנה).
  * התוכנה מסופקת כמו שהיא (AS IS). השימוש על אחריותך.

Files / קבצים:
  Start.bat          - launcher / קובץ ההפעלה
  QlyxFlash.ps1      - the program / התוכנה עצמה
  src\               - source code / קוד המקור (build.py בונה את QlyxFlash.ps1)
