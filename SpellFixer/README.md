# מתקן שגיאות כתיב (SpellFixer) – תוסף לכרום / Edge

תוסף שמזהה שגיאות כתיב בכל אתר ומתקן אותן בלחיצה.

## מה הוא עושה
- **בזמן הקלדה** – בכל שדה טקסט (תיבות טקסט, שדות חיפוש, עורכים כמו Gmail/פייסבוק) מופיע עיגול קטן בפינת השדה:
  ירוק ✓ = אין שגיאות, אדום עם מספר = נמצאו שגיאות. לחיצה עליו פותחת רשימה עם הצעות תיקון,
  וכפתור **"תקן הכל"**. התיקון נשמר בהיסטוריה, כך ש-`Ctrl+Z` מבטל אותו.
- **סריקת דף** – מסמנת בקו גלי אדום את השגיאות בתוכן הדף. לחיצה על מילה מסומנת מציגה הצעות תיקון.
- **מילון אישי** – הוסיפו תיקונים משלכם (`שגוי = נכון`) ומילים שלא יסומנו כשגיאה (או לחצו "התעלם").
- **תפריט לחצן ימני** – "תקן את כל שגיאות הכתיב בשדה" / "סרוק את הדף לשגיאות כתיב".
- **קיצורי מקלדת** – `Alt+Shift+F` תיקון השדה הפעיל, `Alt+Shift+S` סריקת הדף.

## שפות
- **עברית** – מילון מובנה של שגיאות כתיב נפוצות (כולל זיהוי אותיות שימוש: "ובעיקבות" ← "ובעקבות"),
  מילים כפולות ("של של") ורווחים כפולים, ועוד המילון האישי שלכם. עובד ללא אינטרנט.
- **אנגלית, רוסית, ערבית, צרפתית, גרמנית, ספרדית ועוד** – בדיקה מלאה דרך שירות
  [LanguageTool](https://languagetool.org) (אפשר לכבות בהגדרות). אפשר להפעיל גם בדיקת דקדוק ופיסוק.

## התקנה
1. הורידו את התיקייה `SpellFixer` (או חלצו את `SpellFixer.zip`).
2. פתחו בכרום את הכתובת `chrome://extensions` (ב-Edge: `edge://extensions`).
3. הפעילו **מצב מפתח (Developer mode)** בפינה.
4. לחצו **Load unpacked / טען פריט לא ארוז** ובחרו את התיקייה `SpellFixer`.
5. הצמידו את האייקון לסרגל הכלים ורעננו דפים פתוחים.

## פרטיות
- הבדיקה המקומית (עברית ומילון אישי) נעשית כולה במחשב שלכם.
- כשהבדיקה המקוונת פעילה, רק טקסט שאינו בעברית נשלח ל-`api.languagetool.org`.
- שדות סיסמה, שדות אימייל ועורכי קוד (`spellcheck="false"`) לא נבדקים לעולם.

## הערות
- תיקון בתוך תוכן הדף (לא בשדה עריכה) משנה רק את התצוגה אצלכם – לא את האתר עצמו.
- השירות החינמי של LanguageTool מוגבל לכ-20 בדיקות בדקה; בדפים ארוכים נבדקים כ-60,000 התווים הראשונים.

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות התוסף (Manifest V3) |
| `background.js` | פנייה ל-LanguageTool, תפריט לחצן ימני, קיצורי מקלדת |
| `content.js` | בדיקת שדות, סריקת הדף, חלונית התיקונים |
| `lib/checker.js` | לוגיקת הבדיקה המקומית ומיזוג תוצאות |
| `lib/dictionary.js` | מילון שגיאות נפוצות בעברית ובאנגלית |
| `popup/` | חלון ההגדרות שנפתח מהאייקון |
