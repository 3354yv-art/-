ממיר ומשחזר 3.0 / Converter & Recovery
======================================

איך מפעילים / How to run:
  1. חלצו את קובץ ה-ZIP לתיקייה (לחיצה ימנית > חלץ הכל).
     Extract the ZIP to a folder (right-click > Extract All).
  2. לחיצה כפולה על Start.bat, ואשרו את חלון ההרשאות.
     Double-click Start.bat and approve the admin prompt.
  אם מופיע "Windows protected your PC": "מידע נוסף" ואז "הפעל בכל זאת".
  If Windows shows "Windows protected your PC": More info > Run anyway.
  דרוש Windows 10 או 11. אין צורך להתקין כלום.

מה יש בתוכנה:
  שחזור קבצים         - מדריך "מה קרה לקובץ?" + שחזור עם השמות המקוריים (Windows File Recovery)
  המרת קבצים          - תמונות (כולל HEIC מאייפון, תמונות ל-PDF), שמע ווידאו (FFmpeg),
                         מסמכים ו-PDF (דרך Office או LibreOffice)
  העברה ממחשב למחשב   - אריזה במחשב הישן ופריסה בחדש: תיקיות, סימניות, רשתות Wi-Fi, רשימת תוכנות
  סל המיחזור           - שחזור למקום המקורי או העתקה
  גרסאות קודמות        - פתיחת צילומי כונן (נקודות שחזור) והעתקת גרסה ישנה
  מסמכים שלא נשמרו     - קבצים זמניים של Word/Excel/PowerPoint/פנקס הרשימות/Notepad++
  קבצים שנעלמו         - חיפוש בכל המחשב, כולל תיקיות מוסתרות
  סריקת עומק           - חילוץ תמונות/מסמכים/סרטונים לפי חתימה, גם אחרי פרמוט (גם מקובץ .img)
  העתקה מכונן פגום     - העתקה שמדלגת על אזורים פגומים ולא נתקעת
  גיבוי כונן לקובץ      - עותק מלא של כונן לקובץ .img
  תיקון שגיאות בכונן    - מצב בריאות הדיסקים + chkdsk

קבצים / Files:
  Start.bat               - קובץ ההפעלה / launcher
  ConverterRecovery.ps1   - התוכנה עצמה / the program
  src\                    - קוד המקור / source (build: python src\build.py)
