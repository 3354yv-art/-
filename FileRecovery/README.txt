File Recovery / שחזור קבצים
============================

How to run / איך מפעילים:
  1. Extract the ZIP to a folder (right-click > Extract All).
     חלץ את קובץ ה-ZIP לתיקייה (לחיצה ימנית > חלץ הכל).
  2. Double-click Start.bat and approve the admin prompt.
     לחיצה כפולה על Start.bat, ואשר את חלון ההרשאות.
  If Windows shows "Windows protected your PC": More info > Run anyway.
  אם מופיע "Windows protected your PC": לחץ "מידע נוסף" ואז "הפעל בכל זאת".

Files:
  Start.bat          - launcher / קובץ ההפעלה
  FileRecovery.ps1   - the program / התוכנה עצמה
  src\               - source code / קוד המקור
